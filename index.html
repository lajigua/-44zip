使用流程

    
完整链路：解密 → 编辑 JSON → 回打包（自动完成 LZ4 / AES / UnityFS 重建 / CRC 修复 / 重开校验）。

    
    
      
  1. 解密浏览页：选 assetbundle + 输入密钥 → 点「解密并解析」。
    2. 
      
  2. 下载「可编辑 JSON」（推荐）或「XML」，用任意编辑器修改字段。
    3. 
      
  3. 回打包页：选原始 bundle + 编辑后的 JSON + 同一密钥 → 点「回打包」。
    4. 
      
  4. 下载新的 assetbundle 放回游戏目录。
    5. 
    

  

  

    
格式说明

    
    
      
  • 可编辑 JSON：字段键形如 "Int32 scriptType"，继承同名带类名前缀。
    • 
      
  • 语义 JSON：semantic 格式，多态对象请保留 $type 标记。
    • 
      
  • XML：旧版 AnimationData 可读格式。
    • 
      
  • 三种格式回打包时自动识别，无需选择。
    • 
    

  

  

    
注意事项

    
    
      
  • 回打包后文件比原版大属正常（未压缩 LZ4 存储），游戏可正常加载。
    • 
      
  • CRC32 会自动修复为原包值；完成后自动重新解密校验字节与语义一致性。
    • 
      
  • 解密报「无法跳过的未知字段」说明游戏又更新了 schema，需更新内置 kfb_schema.json。
    • 
      
  • 所有处理均在手机本地完成，不上传任何数据。
